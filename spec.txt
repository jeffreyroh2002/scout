📄 PROJECT SPEC — Travel Price Comparison MVP (UNIQLO)
1. Product Goal

Build a mobile MVP that allows travelers to take a photo of a UNIQLO clothing tag, extract the UNIQLO Product ID, and compare prices for the same product across US, Japan, Korea, and EU.

The app prioritizes speed, reliability, and clarity over completeness.

6. Detailed Logic
OCR Pipeline

Capture image

Run OCR

Return all detected text as an array of strings

Product ID Extraction

Extract all 6-digit numbers using regex:

\b\d{6}\b


Rank candidates using heuristics:

Appears near hyphen

Appears once

Appears near center/top of image

Select highest-confidence ID

Validation

Construct UNIQLO product URLs using Product ID

If at least one region returns HTTP 200 → valid

7. UNIQLO URL Patterns

Use Product ID to build URLs:

US: https://www.uniqlo.com/us/en/products/E{PRODUCT_ID}-000/00
JP: https://www.uniqlo.com/jp/ja/products/E{PRODUCT_ID}-000/00
KR: https://www.uniqlo.com/kr/ko/products/E{PRODUCT_ID}-000/00
EU: https://www.uniqlo.com/eu-ee/en/products/E{PRODUCT_ID}-000/00

10. Acceptance Criteria

The MVP is successful if:

User can scan a real UNIQLO tag

App correctly extracts a 6-digit Product ID

App fetches prices from at least 2 regions

App displays a clear comparison

Total scan → result time < 3 seconds
